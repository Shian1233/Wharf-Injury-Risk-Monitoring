# 数据口径、模型与算法

## 原字段与分析数据

`config/schema.json` 从原工作簿提取：事故报告 33、企业数据 79、气候环境数据 70、经济社会数据 72 个字段。DM8 原业务字段使用带引号的中文列名；内部 `_id/_file_id/_hash/_industry/_region/_date/_version/_created_at` 用于关联原件、去重、索引和并发控制，不改动原业务字段。

字段原值保留。报告未明确/报告未区分/不详等按缺失处理，数字转换失败不当作零。金额换算为万元；无单位的事故损失按本次工作簿口径解释为万元，其他来源导入前需确认单位。企业产量、安全投入等存在单位或周期差异的指标不会直接加总。CSV 下载转义 Excel 公式前缀，HTML 显示转义文本。

导入行按原字段内容哈希避免完全重复。同一个事故可能包含调查报告与处理通知，统计使用“省份、归一行业、规范化事故名称、发生日期”合并。同事故数字冲突的字段排除统计并保留冲突计数；不同报告行仍完整保留在数据库。此规则是当前明确的样本归并口径，正式验收应经业务核对，不等同于具有唯一事故编码的权威主库。

日期筛选排除没有发生日期的记录，另行说明排除数量。基本字段完整率定义为发生时间、省份、行业、事故类型、事故等级、死亡人数、直接原因均填写的事故比例，不能解释为区域事故采集完整率。报告快照包含筛选参数、记录 ID/版本/哈希的汇总 SHA256、原件源链接、有效样本数、模型定义与参数，支持复核。

## 事故关联与因素识别

当前使用调查表已有的人员/设备设施/工艺技术/环境/管理原因标记；不让模型凭空新增已认定原因。频次为有效标记的事故数，空标记不代表已经排除该因素。

对因素 A、B，n 为事故样本数：

- 共现数：同时标记 A、B 的事故数量。
- 支持度：共现数/n，以百分比输出。
- 条件置信度：共现数/A标记数，以百分比输出，有方向。
- 提升度：(共现数×n)/(A标记数×B标记数)。
- 重要度：该节点所有边共现数之和，属于加权度。

共现网络揭示关联线索，不证明事故因果。因素组合数是非空原因标记集合的去重数量。自由文本直接/间接原因目前统计“有记录”，没有声称已训练行业语义抽取模型。

## 当前六行业隐患治理与反馈 SD 模型（3.0）

当前业务模型为 `industry-feedback/3.0`，采用隐患压力、累计相对风险负荷和滞后事故信息三个存量，以及隐患形成、隐患消除和相对事故强度三个主要流量。事故报告通过 `app/sd_factors.py` 的行业规则计算专业因素参考值；动态系数均明确标为机制假设。综合风险指数采用固定半饱和转换，数据不足时不输出事故起数、概率或预测区间。

六行业变量、专业因素、映射字段、公式、参数来源、场景作用、报告联动、验证结果及适用边界统一见 [SD_FEEDBACK_MODELS.md](SD_FEEDBACK_MODELS.md)。下节保留 2.0 口径用于历史模型和历史仿真结果复现，不是当前页面首选模型。

### 从报告到可复核参数

`app/industry_risk.py` 按原行业字段选择规则字典，依次在事故类型、事故名称及直接原因中匹配线索。排除局部明确否定表达，不使用整改建议作为事故原因。保存匹配字段、关键词、短原文、报告编号和记录ID；每类快照保留至多三个原文示例，完整计数包括全部筛选记录。重复事故合并后对同类只计一次；一个事故可以涉及多个类别。该提取结果是待业务复核的风险线索，不是新增认定原因，不覆盖原Excel字段，不声称语义抽取准确率已验收。原数据行业分类有误时需先由业务人员修正，程序不自动改写。

设去重事故数为 n，某类匹配数为 c_i，类别数为 K：

- 初始指数 x0_i = 100 × c_i / n。
- 权重 w_i = (c_i + 1) / Σ(c_j + 1)，加1平滑避免完全由单条样本决定权重。
- 管理初值 m0 = 100 × 管理原因标记数 / n；未标记不等于排除管理问题。
- 时间趋势 d_i = (最近半年线索比例 − 前半年线索比例) / 6，单位为指数/月。两个半年均需至少5起事故且覆盖至少3个月；否则返回 `trend: null`、`insufficient`，计算采用中性漂移0，明确未估计趋势。
- 时间窗以用户分析结束月份为锚点；用户未给结束时间时使用样本最新月份。趋势是样本构成变化，不是地区事故率；采集偏差、公开延迟和窗口内覆盖不均仍需审核。

用户可以调整生产压力 P、安全投入 S、风险调整时间 T、治理速率 R；由事故数据计算的参数禁止通过运行请求直接覆盖，如需改变取值方式，应通过后台模型维护流程处理。

### 动态方程与明确假设

```
target_i(t) = clamp(x0_i * P * (1 + 0.15 * (m - m0)/100)
                    + d_i * T * (1 - exp(-t/T)), 0, 100)
dx_i/dt = (target_i(t) - x_i)/T - R*S*x_i
dm/dt = (m0*P - m)/T - R*S*m
risk_index = 0.8 * Σ(w_i*x_i) + 0.2*m
```

默认 P=S=1、T=6月、R=0.05/月；管理反馈0.15、行业/管理权重0.8/0.2均为显式建模假设，未通过专家及纵向台账标定。使用 RK4、0.05月步长，每一步保存实际计算结果，即每月20个间隔，三个月含起点共61点，并约束存量在0至100；未对结果插值造点。历史快照保持原采样密度，重新运行后使用密集采样。高风险持续时间按相邻采样的实际时间间隔积分，阈值交叉在该区间内作线性估计，避免把加密后的点数误计为月数。压力场景P×1.2，投入减少场景S×0.8；参数和历史版本均记录在运行结果中。界面的自适应纵轴不改动数值。

同一数值积分框架复用到六行业，但风险类别、匹配规则、初值、权重和可用趋势分别由对应行业报告决定。指数不是事故概率或未来起数，情景曲线可运行不等于预测准确性达标。当前真实样本的半年趋势均不足，正式机理模型和专家审核仍待接入。

公式由 AST 白名单解释器计算，不允许属性访问或执行任意代码。未知变量、行业标定字段不匹配、辅助变量代数循环、参数越界、除零或发散会被拒绝。模型图展示实际依赖关系，图下为只读中文计算规则；运行时仍执行后端模型校验。

启动时只把名称、参数及公式仍与旧内置定义相同的模型升级为新版本，保留原ID和全部历史快照；已有自定义模型完整保留，并新增行业模型。重复启动不重复升级。源文件 `models/1.json` 至 `6.json` 包含当前定义。

Vensim `.mdl` 仍支持数值参数、标量公式及 INTEG 子集；复杂查表、延迟、数组及XMILE完整转换不在当前实现范围。模型导出保持可交换的机器格式，日常页面不展示原始代码。

## 事故计数预测与置信度

预测默认关闭计算，直到用户确认分析范围事故采集完整，并提供至少 24 个完整自然月和至少 30 条具有时间的事故样本。部分自然月或没有采集完整性确认时，不能将空月补为零。

采用惩罚 Poisson 回归，特征为截距、时间趋势、年度正弦和余弦；IRLS 类 Newton 更新估计参数。时间索引尺度由约定完整月长度确定，不使用未来事故值。使用末期 6–12 个月逐月滚动单步回测，每次训练只含测试月以前的数据，避免随机切分时间泄漏。

从估计参数及协方差抽样，再经 Poisson 抽样生成计数预测区间；另给均值 90% 区间。当前是近似参数不确定性传播，不是已经完成行业外部验证的可靠置信保证。随机种子固定 20261013。返回 MAE、逐月误差评分、90%区间实际覆盖率以及真实/预测序列。

误差评分定义为逐月 `max(0, 1-|预测-实际|/max(实际,1))` 的平均值，以百分比显示。该定义仅供透明复算；验收准确性指标、预测单位、地区层级、时间粒度和置信要求尚待约定。标称 90% 预测区间不等于 90% 准确率，`accepted` 始终为 false，直到独立样本与约定口径完成核验。程序测试中的构造序列用于验证时间切分和算法，不作为业务验收数据。

## 报告与 LLM 约束

查询 → 事故统计 → 原因关联 → 计数预测条件校验 → SD仿真 → 综合指标 → DeepSeek定性文字 → 服务端定量段落 → 七章HTML → PDF。

LLM 只负责定性叙述。输出中的数字、数量、日期、证据槽位、HTML或内部协议句子整句排除，保留符合规则的定性正文，并记录排除数量；剩余段落不足或校验失败时重试一次，仍失败则输出有明确状态的规则文本草稿。服务端按“指标名—真实结果—单位—有效样本—统计口径”直接生成定量句子与表格，避免模型错用另一个指标的数字。定性建议仍需业务审核，程序不保证语言解释或专家一致性自动达标。

按真正排入模板的正文段落统计汉字数，不计封面、目录、表格或未排入模板的段落，要求不少于 3000。七章标题与原模板保留，PDF 使用实际渲染页码回填目录，正文流式分页。HTML 使用相同计算快照；修改数据后需另建新报告，不改写历史证据。

问答使用查询和 SD 工具白名单，限制调用轮次。所有问答定量内容通过服务器绑定的证据槽位填入；工具轨迹与来源供用户核对。问答中语言对证据的解释仍有模型局限，重要研判应查看计算证据并审核。
