# 六行业隐患治理与反馈 SD 模型

实现版本：`industry-feedback/3.0`。模型文件位于 `models/1.json` 至 `models/6.json`，可执行定义位于 `app/sd_feedback.py`，行业因素规则位于 `app/sd_factors.py`。本页说明普通业务页面背后的计算口径；页面只显示中文业务名称、关系图、参数表单和仿真结果。

## 1. 统一动态结构

六个行业共用同一套可解释的隐患治理闭环，并分别加载行业专业因素。

| 类别 | 变量 | 含义与单位 |
|---|---|---|
| 核心存量 | 隐患压力 H | 归一化模拟状态，不是未整改隐患数量 |
| 累计存量 | 累计相对风险负荷 L | 相对事故强度的时间积分，不是预计事故起数 |
| 滞后存量 | 滞后事故信息 D | 一阶信息延迟，单位为相对强度/月 |
| 主要流量 | 隐患形成速度 G | 生产压力与专业因素推动，单位为归一化状态/月 |
| 主要流量 | 隐患消除速度 R | 治理水平和隐患压力共同决定，单位为归一化状态/月 |
| 主要流量 | 相对事故强度 λ | 隐患压力、作业暴露和专业因素共同决定，单位为相对强度/月 |
| 输出 | 综合风险指数 I | 固定转换到 0–100 分，不是事故概率 |

以月为统一时间单位、`dt=0.05` 月进行 RK4 数值积分，每月 20 个计算间隔。各场景从同一初始状态开始，1、3、6、12 个月分别包含 21、61、121、241 个含起点的真实计算点。

```text
H(t+dt) = max(0, H(t) + [G(t)-R(t)]×dt)
L(t+dt) = max(0, L(t) + λ(t)×dt)
dD/dt    = [λ(t)-D(t)] / 治理响应滞后

G = 基准形成速度 × 生产压力 × [1 + 专业因素综合作用]
R = 基准消除系数 × 安全治理水平 × H
λ = 相对强度换算系数 × 相对作业暴露 × H × [1 + 专业因素综合作用]
I = 100 × λ / [固定半饱和强度 + λ]
```

化工模型中的“泄漏检测与处置能力”是保护因素，只能降低相对事故强度，不会作为正向风险权重相加。风险指数使用固定半饱和转换规则，前端缩放和场景选择不会篡改计算结果。

## 2. 六行业专业因素

| 行业 | 专业因素 | 特殊适用处理 |
|---|---|---|
| 煤矿 | 瓦斯及通风、顶板支护、水害、违规采掘 | 各因素使用独立权重、压力弹性和治理敏感度 |
| 金属非金属矿山 | 采空区与顶板、边坡稳定、排水及水害、爆破作业、运输提升 | 地下、露天、尾矿库可显式选择；非适用因素不进入计算 |
| 石油天然气开采 | 井控、设备及管线泄漏、硫化氢暴露、高压作业、检维修及动火 | 井控与泄漏形成联合作用 |
| 化工 | 危险工艺控制、腐蚀与密封失效、危险物质储存、特殊作业、泄漏检测与处置能力 | 检测处置作为保护能力，危险工艺与密封失效形成联合作用 |
| 烟花爆竹 | 超员作业、超药量、混装药、静电及火源控制、危险品库存 | 超员与超药量形成联合作用 |
| 工贸 | 高处作业、机械设备防护、有限空间、危险作业管理、特殊生产工艺 | 粉尘涉爆、涉氨制冷、高温熔融按报告识别或由用户选择适用性 |

所有因素参数均有中文名称、取值范围、单位、来源和作用方向。动态系数当前标记为“机制假设，尚未经历史数据或专家标定”，没有把随机权重包装成回归结果。

## 3. 事故报告字段与因素映射

规则只读取系统真实存在的字段：`直接原因、间接原因、事故类型、事故名称、作业场所、作业环节、作业活动、人员原因、设施设备原因、工艺技术原因、环境原因、管理原因`。同一事故可以命中多个因素。

每次命中保存：事故记录 ID、事故编号、字段名、关键词、原文片段、映射理由和规则版本 `industry-factors/3.0`。页面“查看依据”可逐条复核。局部明确的“未发生、未涉及、未发现、不适用、排除”等否定表达不计为命中。

每个行业分别计算去重样本数、因素频次、占已收录样本比例、因素共现和适用范围切片。因素比例只用于初始化相对状态，不能解释为现场发生概率、行业事故率或因果效应。没有命中也不表示现场不存在风险。

## 4. 参数初始化与来源

非保护因素的参考值优先使用适用范围内“该因素命中事故数 / 去重事故样本数”。样本或上下文不足时使用 0.5 的显式机制参考值，并在计算快照中标为假设。化工保护能力固定以 0.5 起步，事故报告中的缺陷线索不反推当前企业已具备可靠检测能力。

```text
初始隐患压力 = 0.25 + 0.75 × 适用专业因素参考值的加权均值
```

生产压力、安全投入、治理响应滞后和基准消除系数是页面可调整的情景参数。专业因素参考值默认由报告计算；在“调整模型”中切换为手动后才允许修改。每次仿真结果保存模型快照、参数来源和数据依据。

## 5. 场景、结果与报告联动

| 场景 | 实际进入公式的变化 |
|---|---|
| 基准场景 | 使用当前参数 |
| 生产压力增大 | 提高生产压力，直接改变 G、相对暴露及专业因素压力响应 |
| 安全投入减少 | 降低安全投入，直接改变治理水平 R 和保护能力 |

仿真返回综合风险指数、相对事故强度、隐患压力、累计相对风险负荷、关键因素、三场景末期差异、峰值及峰值月份。曲线、悬停、放大、历史比较和 CSV 导出使用同一组真实计算点。

报告第四章使用因素命中、共现关系和原文依据；第五章使用三场景曲线、峰值及末期差异；第六章按启用因素的治理措施生成建议。报告明确区分历史事故统计、模型情景推演和已经验证的预测结果。

## 6. 中文模型编辑与历史兼容

师生页面不展示 JSON、Python 或内部变量编码。模型编辑器支持中文表单修改变量名称、参数、公式和变量关系，并执行结构、循环依赖、量纲、边界值、非有限数和保护因素方向校验。保存前必须通过校验。

每次保存生成新版本快照，可恢复历史版本。启动迁移保留原模型 ID、自定义模型、用户参数、既有版本和历史仿真结果；重复启动不会重复迁移。界面只呈现当前业务模型，不显示版本选择工具栏。

## 8. 数据不足与适用边界

当前事故调查报告不是完整事故主库，也缺少连续企业暴露量、企业数量、从业人数、生产运行、监管隐患台账和经过验证的发生率参数。因此隐患压力是模拟状态，累计相对风险负荷不是预计事故起数，相对事故强度也不是事故概率。系统不输出事故数量、预测区间或准确率承诺。

行业样本少时只允许机制情景推演，不能声称已完成行业统计标定。正式投用前仍需行业专家审核参数、补充完整暴露数据，并开展时间外回测与覆盖率验证。上述限制随仿真结果和报告快照一起输出。
